📱 C.N. Message

Installe C.N. Message sur ton écran d'accueil pour l'utiliser comme une app.

🍎 iOS

  1. Ouvre C.N. Message dans Safari.
  2. Appuie sur Partager.
  3. Choisis Sur l'écran d'accueil.
  4. Active Ouvrir comme app web si l'option apparaît.
  5. Appuie sur Ajouter.

🤖 Android

  1. Ouvre C.N. Message dans Chrome.
  2. Appuie sur ⋮ en haut à droite.
  3. Choisis Installer l'application si elle est proposée.
  4. Sinon, utilise Installer et créer un raccourci ou Créer un raccourci, selon la version.
  5. Valide l'ajout.
